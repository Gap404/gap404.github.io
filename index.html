vxwm 配置速查

配置文件：~/Dwm_file/vxwm/vxwmdotfiles/myvxwm/config.h
模块开关：~/Dwm_file/vxwm/vxwmdotfiles/myvxwm/modules.h

基本参数

项目 值
MODKEY Mod4Mask（Super/Windows 键）
ALTERNATE_MODKEY Mod1Mask（Alt）
边框宽度 borderpx = 1
窗口间隙 gappx = 10
状态栏 顶部显示（showbar=1, topbar=1）
状态栏文字 JetBrainsMono Nerd Font:size=15
rofi 字体 JetBrainsMono Nerd Font:size=13
显示窗口标题 SHOW_WINTITLE = 1（1=显示，0=隐藏）
状态栏左右缩进 left_sidepad = right_sidepad = 450
状态栏高度 user_bh = 30

启用的模块

配色

用途 颜色
普通窗口 前景 #ebdbb2
普通窗口 背景 #282828
普通窗口 边框 #928374
选中窗口 前景 #282828
选中窗口 背景 #ebdbb2
选中窗口 边框 #ebdbb2

（Gruvbox 风格）

标签（工作区）

标签为 1 2 3 7，共 4 个。

快捷键 功能
Super + 1..9 切换到标签 N
Super + Ctrl + 1..9 切换显示标签 N（toggleview）
Alt + 1..9 把当前窗口移到标签 N
Super + Ctrl + Shift + 1..9 把当前窗口移到标签 N（toggletag，不跟过去）
Super + 0 查看所有标签（view all）
Super + Shift + 0 把窗口移到所有标签

窗口管理

快捷键 功能
Super + j 焦点移到下一个窗口
Super + k 焦点移到上一个窗口
Super + i 增加主区域窗口数（nmaster +1）
Super + d 减少主区域窗口数（nmaster -1）
Super + h 主区域宽度减少 5%
Super + l 主区域宽度增加 5%
Super + Return 与主窗口交换（swapmaster）
Super + Shift + q 关闭当前窗口（killclient）
Super + Shift + m 退出 vxwm（quit）
Super + Shift + Space 切换浮动/平铺
Super + q 增强浮动切换（ENHANCED_TOGGLE_FLOATING）
Super + Shift + f 全屏切换（FULLSCREEN）

布局

快捷键 布局
Super + f 平铺（tile）
Super + t 浮动（floating）
Super + m 单窗口（monocle）
Super + Space 循环切换布局

多显示器

快捷键 功能
Super + , 焦点移到上一个显示器
Super + . 焦点移到下一个显示器
Super + Shift + , 把窗口移到上一个显示器
Super + Shift + . 把窗口移到下一个显示器

间隙（GAPS）

快捷键 功能
Super + - 减小间隙
Super + = 增大间隙
Super + Shift + = 重置间隙

方向焦点（DIRECTIONAL_FOCUS）

快捷键 功能
Alt + ←/→/↑/↓ 按方向切换焦点

键盘移动/缩放（MOVE_RESIZE_WITH_KEYBOARD）

快捷键 功能
Super + ←/→/↑/↓ 移动窗口（步长 50px）
Super + Ctrl + ←/→/↑/↓ 缩放窗口（步长 50px）

无限画布（INFINITE_TAGS）

快捷键 功能
Super + r 回到原点 (0,0)
Super + Shift + ← 画布向左移
Super + Shift + → 画布向右移
Super + Shift + ↑ 画布向上移
Super + Shift + ↓ 画布向下移
Super + Shift + d 窗口居中
Super + Ctrl + z 钉住窗口

启动程序

快捷键 功能
Super + z rofi 应用启动器
Super + p 终端（kitty）
Super + Shift + Return 终端（kitty）
Super + w 壁纸选择（rofi-wallpaper.sh）

dmenu 脚本

快捷键 功能
Super + e 编辑配置文件菜单
Super + Shift + e 编辑当前目录文件
Super + b 网址书签
Super + Shift + b 添加网址书签
Super + y 目录书签
Super + c 剪贴板历史
Super + Shift + r 录屏开关（gsr-toggle.sh）

音量 / 亮度

按键 功能
F2 音量 -5%（pactl）
F3 音量 +5%（pactl）
F5 亮度 -5%（brightnessctl）
F6 亮度 +5%（brightnessctl）
XF86AudioRaiseVolume 音量 +（~/volume.sh i）
XF86AudioLowerVolume 音量 -（~/volume.sh d）
XF86AudioMute 静音（~/volume.sh t）
XF86MonBrightnessUp 亮度 +5%（~/brightness.sh）
XF86MonBrightnessDown 亮度 -5%（~/brightness.sh）

截图

快捷键 功能
Print 全屏截图 → ~/Image/Pictures/Screenshots/shot-日期时间.png
Super + Print 选区截图
Super + Shift + Print 当前窗口截图
Super + Ctrl + Print 选区截图 → 直接进剪贴板
XF86... / Print（vxwm 原生） ~/ss-area.sh

注：Print 有两条绑定（我的 scrot + vxwm 原生 ss-area.sh），实际生效的是先匹配的那条（我加的 scrot）。

缩放（ZOOM）

快捷键 功能
Super + = 放大（vcompmgr）
Super + - 缩小
Alt + r 重置缩放

注意：Super + = / Super + - 同时被 GAPS 和 ZOOM 占用，先匹配 GAPS。

鼠标

操作 功能
Super + 左键拖客户端 移动窗口
Super + 中键 切换浮动
Super + 右键拖 调整窗口大小
Super + Shift + 左键拖客户端 拖动画布（movecanvasmouse）
Super + Shift + 左键拖桌面空白 拖动画布
左键拖桌面空白（无修饰键） 拖动画布
Super + 滚轮上/下 缩放（ZOOM）

状态栏点击

操作 功能
左键点布局符号 切换布局
右键点布局符号 切到 monocle
中键点窗口标题 swapmaster
中键点状态文字 打开终端
左键点标签 切换到该标签
右键点标签 toggleview
Super + 左键点标签 把窗口移到该标签
Super + 右键点标签 toggletag

规则（rules）

class 说明
Gimp 浮动

firefox 标签 2

自动启动（autostart）

状态栏显示内容

vxwm 读取 root window name 显示在栏右侧。

由 ~/.local/bin/vxwm-status 脚本写入：

  • 电量：BAT0/BAT1 平均值，充电加 +
  • 内存：已用/总量（3.6G/7.6G）
  • 时间：HH:MM
  • 刷新间隔：10 秒

常用命令

已知问题 / 备注

  1. Print 键重复绑定：我的 scrot 在前，vxwm 原生 ss-area.sh 在后，实际用 scrot。
  2. Super + = / - 冲突：GAPS 和 ZOOM 都绑了，先匹配 GAPS。
  3. Super + Shift + q 在 vxwm 原生是 quit，但已被我改成 killclient（Super+Shift+m 才是 quit）。
  4. 状态栏颜色：写死在 config.h（Gruvbox），不跟随 wal。
  5. 画布拖动：无修饰键拖桌面即可移动画布（INFINITE_TAGS 功能）。
